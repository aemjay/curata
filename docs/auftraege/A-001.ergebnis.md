## (3) Was nicht ging und warum

1. **`python3`** ist auf Windows nur der Store-Alias → stattdessen `python -m http.server 8000`. Die Anleitung in `CLAUDE.md` („`python3 -m http.server`") gilt auf diesem Rechner nicht wörtlich.
2. **Playwrights eigenes Chromium 131** (`chrome.exe`) startet auf Windows Build 26300 nicht („Side-by-Side-Konfiguration ungültig"); nur `headless_shell` läuft, das für GPU-Aussagen ungeeignet ist. Lösung: Playwright mit `channel: 'chrome'` → installiertes Chrome 155. Für künftige Läufe so beibehalten (in `A-001/screenshot.mjs` Standard).
3. Playwright liegt bewusst **nicht** im Repo (Zero-Build); das Skript erwartet `PW_PATH` auf eine lokale Installation (`npm install playwright@1.49.1` in einem Arbeitsordner).
4. `favicon.ico` fehlt in `photobook/` → 404 in der Konsole. Kosmetisch, nicht Teil dieses Auftrags.
